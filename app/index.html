      兩台裝置同時修改的紀錄

      同一筆資料在兩台裝置都被改過時，只有兩邊改到的同一欄會用這台的值，其他欄位都保留。請確認下面這幾筆是對的。

        GitHub 金鑰（每台裝置設定一次）

        1. 打開 GitHub 新增 Fine-grained token。
        2. Repository access 選 Only select repositories → 勾 wife-finance。
        3. Permissions → Repository permissions → Contents 選 Read and write，其他不用動。
        4. 按 Generate token，把 github_pat_ 開頭的那串貼到下面。
